# Menu Studio

Replaces the Windows desktop right-click menu (empty desktop area only) with a menu you fully style: shape, color, gradient, blur/transparency, border, shadow, font, icons, hover style, 12 opening animations with easing, one-by-one item animation, closing animation, 14 themes, your own items and order.

Safety: no DLL injection, no registry changes to Explorer, no system files touched. It uses one standard mouse hook inside its own process. Hold Shift while right-clicking for the normal Windows menu. Exit the app from the tray icon and everything is back to normal.
